# MappingCalc 2.0.0

## New features

* Added EQ_PHQ8 calculator: maps PHQ-8 scores to EQ-5D-5L using a validated
  2-component Beta Mixture Model.
* Added EQ-5D-5L direct profile lookup using Singapore value set.
* Added Data Analysis module: descriptive statistics, linear regression,
  cost-utility analysis (ICER), and probabilistic sensitivity analysis (CEAC).
* Batch processing via CSV/XLSX upload for all calculator modules.
* Offline use as an installable R package via run_app().

## Breaking changes

* None. This is the initial CRAN release.
